# Java Beverage Order System

A Java program that demonstrates the use of interfaces and object-oriented programming.

The program uses a Beverage interface that is implemented by Coffee and Tea classes. A DrinkOrder class stores beverage objects and calculates the total price of an order.

## Concepts Demonstrated
- Java interfaces
- Object-oriented programming
- Classes and objects
- ArrayLists
- Method implementation
- Polymorphism
- Decimal/price formatting
